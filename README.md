# Exhibit Image Annotation

The Exhibit Image Annotation plugin for Omeka Classic adds a content block type to Exhibit Builder that allows you to create and display annotations for an image.

This plugin works with and requires the Exhibit Builder plugin.

See the [Exhibit Image Annotation page in the Omeka Classic user manual](https://omeka.org/classic/docs/Plugins/ExhibitImageAnnotation/) for user documentation.
